# Tataview

논문·노트를 **읽고 표시하는** 맥 앱. md·PDF·워드·엑셀을 열어서 형광펜·밑줄·포스트잇·태그를 달고, 표는 엑셀처럼 걸러보고, 오른쪽에 붙어 있는 Claude Code한테 정리를 시킬 수 있어.

## 받기
[Releases](../../releases)에서 최신 `Tataview-버전.dmg`를 받아서 열고, Tataview를 Applications로 끌어다 놓으면 돼.
자세한 건 [설치 안내](설치_안내.md).

## 이런 앱이야
- **읽기**: md, PDF, 워드(docx), 엑셀(xlsx), CSV. 원본은 절대 안 바뀌고, 저장하면 Tataview 폴더에 사본이 생겨
- **표시하기**: 형광펜 5색, 밑줄, 포스트잇 메모지(서식·색·격자), `#태그`, 태그 그래프
- **표**: 칸마다 엑셀식 필터(▾), 노트 칸 바로 쓰기, 편집 모드, CSV 내보내기
- **Claude Code**: 앱 오른쪽에서 바로. 파일 만들기·옮기기·정리, 스크린샷 붙여서 묻기, 대화 자동 기억
- **화면**: 패널 접기·너비 조절, 테마(라이트·다크·겨울 밤·딸기 말차·겨울 아침·콘플라워·프로스트 앤 엠버·크리스마스·직접 정하기)
- **저장**: 워드처럼 ⌘S. 저장 안 하고 닫으면 물어봐

## 필요한 것
- M칩 맥, macOS 13 이상
- [Claude Code](https://docs.anthropic.com/claude-code) 설치·로그인 (오른쪽 Claude 칸용)

## 피드백
앱 메뉴 **Tataview → 피드백 보내기…** 또는 앱 오른쪽 Claude한테 "불편했던 거 정리해서 Tataview 피드백 보내줘". GitHub 계정 없어도 돼.
